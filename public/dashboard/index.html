            Twitch

            Lets the Dashboard change the stream title and category. Connect the channel's own account: Twitch only lets a channel's owner change these.

            1. Register an application at dev.twitch.tv/console/apps, with Category Broadcaster Suite, Client Type Confidential, and this OAuth Redirect URL:
            2. Paste the application's Client ID and Client Secret below, and save.
            3. On the OBS PC, at http://localhost:3000, click Connect Twitch account and sign in as the channel.

            Stream Deck

            Run the timer from a Stream Deck. For each button:

            1. Add a Website action (in the System category).
            2. Paste one of the addresses below as its URL.
            3. Tick Access in background, so it doesn't open a browser.

            The button shows a checkmark when it worked, and an alert when the timer can't do that right now (like Pause when it isn't running). Other HTTP tools, such as Bitfocus Companion, can use the same addresses with GET or POST.

            The key at the end of each address stops other websites from pressing these for you. If an address gets shared, generate a new key, then paste the new addresses into your buttons.

            OBS text files

            Choose where each field is written. A file name or relative path goes inside the output folder; a full path can go anywhere. Every location must end in .txt. Fields marked 1–4 write one file each, with {n} replaced by the performer or run number.

            NUCLEAR RESET

            Erases all data and settings and starts the app over from scratch:

            • Every performer in the directory
            • The Live Segment, Next Segment, Future runs and the timer
            • The imported schedule and the Horaro settings
            • Every setting on this page: the Twitch connection, the output folder, file locations and the uploaded timer font

            Every OBS text file is written blank. A backup copy of everything is saved in data/backups first.
